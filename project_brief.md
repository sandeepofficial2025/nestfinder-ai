# My agent: NestFinder AI
One-liner: A conversational agent that helps renters find, evaluate, and visualize apartment listings based on their budget, lifestyle, and preferences.

Tool coverage:
- Memory: Remembers budget constraints, target neighborhoods, pet rules, and required amenities across sessions.
- Tools: search_listings (queries property catalog) and schedule_tour (books listing viewing times).
- Catalog/UI: Renders property listing cards with price, beds/baths, square footage, and amenities tables.
- Image gen: Generates virtual interior staging previews for listings on demand.
- Sandbox: Computes rent-to-income affordability ratios and total move-in cost breakdowns.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for rent affordability calculations, Cloud Trace
